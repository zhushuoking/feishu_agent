# 项目阶段总结与组员交接

本阶段收尾，不继续新增功能。原 Mac 生产工作区及凭据、SQLite、OAuth 密钥和审计保留在原机器，未随仓库上传。共享副本中的环境资源标识已替换为匿名占位值，不能直接连接个人生产环境。

## 总体进展与架构

群消息由 SDK 长连接进入 Agent，解析真实 mentions，产生人工确认卡；确认后写 SQLite 正式任务与负责人关系。状态机及操作者权限决定合法动作，Worker 处理持久事件、通知及同步。个人日历先成功，再由 task_table_sync 将任务投影为多维表格一条稳定记录，工作台读取同一数据源。表格不是任务状态权威，不反向控制 Agent。

既有能力：单人与多人任务、确认建单、状态机、任务卡、去重、发件箱；Mac 后台启停、消费者检查、策略摘要、预算、安全停止和备份；个人 OAuth 加密保存、个人事件映射和状态同步；普通任务表同步、未知新增结果查询、record_id 持久映射、完成取消更新、旧映射保留。实际使用新任务已验证写入原工作台，完整多人真实生命周期仍需受控验收。

新增关键模块：scripts/ 下运行边界及启动器；task_table_sync.py；workbench_profile.py；meeting.py、meeting_jobs.py、meeting_config.py。业务改动集中在日历、消息识别与任务接入钩子；原 Windows main.py / worker.py 入口保留。

## 尚未完成及外部限制

工作台记录级权限、每人只看本人、全员安全开放、AI 页面个性化均未完成。实际组织套餐不支持指定记录的行列权限，需组织管理员升级并分配所有者席位。链接分享已收紧，禁止用普通筛选冒充权限；不要开发第二套权限系统绕过套餐。

会议链路 A 为表格新增后由飞书自动化创建日程；链路 B 包含指令解析、真实参会人、独立预算/幂等账本及 Worker 查询回写和最终通知。代码及离线测试不等于开启生产。Mac 正式运行策略会议关闭，不能声称会议完整真实闭环已验收。外部自动化仍须由目标环境所有者检查，不得直接套用个人生产配置。

## 安全配置及权限

复制 .env.example 为本机 .env，按 README 配置应用 ID/Secret、模型 URL/Key、允许群、机器人 open_id、个人日历与 OAuth 回调。每位成员自行授权个人日历；绝不共享 refresh token 或加密密钥。仓库 config 中资源占位符须用自己的 Wiki/Base/table 配置替换，核验 schema 后再启用。占位配置不是生产就绪授权；不得复制他人的运行 policy/confirmed 文件。

权限清单以 feishu-permissions.json 为准，按实际启用功能申请最小权限，包括现有消息/卡片、个人日历与 OAuth，以及 Wiki 节点读取、表/字段读取、记录创建/更新/检索。机器人资源编辑权限和应用 API scope 是两层，普通成员不继承机器人权限。不要一键扩大权限。

## Mac 运维

安装受支持 Python，创建 .venv，pip install -r requirements.txt。项目目录执行 ./start.sh setup 阅读并确认范围，再 ./start.sh；./status.sh 查看，./logs.sh 查看脱敏日志，./stop.sh 安全停止。正式库和密钥不删除，不开机自动运行，不允许两台机器消费同一个 App。阶段维护时保持停止。

.local 为机器私有运行目录；不纳入 Git。使用 SQLite backup API 一致性备份，保留账本和密钥关联。恢复前停止所有消费者，先备份当前状态，不得只恢复 task 表而丢失日历及表格映射。启用新目标必须保留每任务原目标归属及 cutover，不做历史回填。

## Windows 接入与静态兼容检查

使用 python -m venv .venv，PowerShell 执行 .venv\Scripts\Activate.ps1，然后 pip install -r requirements.txt。先运行离线测试，确认目标应用无其他消费者后，两个终端分别 python main.py 和 python worker.py。原项目 bat 工具仍保留。Mac 的 shell、ps、进程组与策略入口不宣称可直接在 Windows 使用；共享业务代码保留 pathlib/SQLite 路径处理。没有 Windows 实机环境，本轮仅静态检查，Windows 同学须验证编码、SQLite 锁、依赖及 OAuth 回调。

数据库模型见 models_db.py，初始化/升级见 db.py。只在临时副本做迁移演练，记录新列默认值与索引，核验旧任务 uid、个人事件 ID、record_id 未丢失；不能删除正式库“解决迁移”。

## 测试和协作

离线测试必须禁用本机 dotenv（PYTHON_DOTENV_DISABLED=1），用构造人员、临时 SQLite 和假 API，禁止真实发送通知或创建任务日历。测试结果以此次 PR 描述和 test-results 为准；不要把历史文档中的检查数量当作本轮结果。真实验收另行授权，会议尤其需要补验。

从功能分支审查，PR 为 Draft；不要直接改远程 main。重点审查运行安全边界、个人凭证存储、多人同步、未知结果恢复、环境配置与 Windows 兼容。后续先修复阻断回归，再做真实多人验收；套餐权限开通后再处理工作台隔离。不要同时启动同 App 的第二个机器人。
