# 组员快速上手

分支：feat/agent-mac-integration-handoff。先审查 Draft PR，不直接合并 main。

1. git fetch origin，然后 git switch --track origin/feat/agent-mac-integration-handoff。
2. Windows 安装受支持 Python，运行 python -m venv .venv；激活 .venv\Scripts\Activate.ps1。
3. pip install -r requirements.txt。
4. 复制 .env.example 为 .env，配置自己的应用、模型及测试群。config 下均为匿名占位资源，必须核验并替换，不能直接连接生产。个人日历需本人 OAuth，不共享密钥。
5. PowerShell 设置 $env:PYTHON_DOTENV_DISABLED='1'，运行 python -m pytest -q tests tests_mac。离线用临时库和假 API，不创建真实日程或通知。运行前移除测试变量再启业务。
6. 确认原 Mac 已停止，整个团队同一 App 仅一台运行。Windows 使用原 python main.py 与 python worker.py；Mac 使用 start/status/logs/stop.sh。

重点看 calendar_auth.py、calendar_sync.py、task_table_sync.py、workbench_profile.py、scripts/*boundary.py、scripts/mac_live.py、meeting*.py。所有任务动作仍从原卡片执行，表格只读投影不反向控制。

限制：Windows 仅静态检查；会议生产关闭且完整真实闭环待验收；工作台记录权限受套餐限制，尚未全员开放；AI 首页未完成个人隔离。不要用共享视图筛选替代访问权限。生产数据库、运行授权、OAuth、日志均不在 Git，不能把另一台机器的 .local 拷过来直接启动。

完整说明见《项目阶段总结与组员交接.md》及 PR 的实际测试结果。
