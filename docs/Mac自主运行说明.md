# Mac自主运行说明

2026-11-27。唯一项目：`<PROJECT_ROOT>`。

## 第一次亲手操作

打开Mac终端，复制：

```sh
cd <PROJECT_ROOT>
./start.sh
```

第一次会显示应用、租户、授权群、功能和运行策略。核对后输入中文 `确认`，程序保存本机持久确认并继续后台启动。未确认不会连接飞书。没有固定8/12小时到期，不需要你创建JSON或计算SHA256。

初始待确认范围由当前已核验配置整理：

- 应用：任务自动跟进Agent，`cli_fixture18`。
- 租户：`EXAMPLE_RESOURCE_11`；单个授权群：`oc_fixture17`。
- 任务识别、真实多人@、人工确认、卡片状态流转继续使用原业务模块。
- 个人日历既有授权账号的刷新和同步保留，仍受owner-only、历史任务截止ID与日历API映射控制。
- **会议功能关闭**，链路A未启用；不会因启动方式变化而创建会议。
- **新日历OAuth连接暂关闭**：此前临时HTTPS隧道已到期，自主模式不启动或复用过期隧道。已有账号同步不依赖该隧道；需要连接新的个人日历账号时，须先配置长期有效的HTTPS回调并确认范围，不能把旧临时地址当作可用回调。

看到 `自主运行 READY` 才表示Agent和Worker都完成启动。之后可关终端，后台仍运行。不会随Mac开机自动启动。Mac休眠或断网会影响连接；本版不自动无限重连，连接退出后安全停机，需你查看原因并重新启动。

## 日常四个命令

```sh
./start.sh
./status.sh
./logs.sh --follow
./stop.sh
```

重复启动会拒绝第二个消费者。状态显示 `AUTONOMOUS READY Agent + Worker`；异常时显示告警或停止。日志仅输出脱敏阶段、累计计数和错误类型，不输出凭证、聊天原文或请求正文。日志查看可按Control+C退出，服务不受影响。

停止会先退出宿主并清理Agent和Worker，保留数据库、备份、策略和审计。正常停止后再执行 `./start.sh` 即可，不重新申请授权；不要并行开启另一个live/daily实例。

## 长期运行的保护

原Guard继续生效。自主模式采用确认过的持久策略、滚动限额和累计审计，受控模式仍使用原到期授权。当前默认HTTP每分钟120次、每小时2400次，各操作另有更小配额；鉴权、模型、建单、卡片和日历请求统一计数，重启不会清零分钟/小时计数及历史累计数。

授权群、应用及租户校验、真实机器人身份过滤、成员角色、消息幂等、人工确认和个人日历传输边界保留。网络请求超时限制15秒；禁止隐式重试与自动跳转。Worker无心跳超过180秒、子进程退出、请求失败、配额耗尽或代码/配置变化，会撤销当次运行并清理进程，不自动重新启动。

每次真实启动前使用SQLite在线备份并核验完整性。自主模式新增备份累计达到默认1GiB、审计库达到100MiB时会提醒处理并安全拒绝启动/停止运行；不会因固定时长到期停机。旧授权、旧审计、正式业务库和历史会议记录均不会删除。备份和审计应定期由所有者归档，禁止为规避错误直接清空记录或重放未知请求。

持久配置位于 `.local/autonomous/policy.json`，确认记录位于同目录 `confirmed.json`；内部摘要自动管理。不要复制旧daily授权来冒充自主配置。需要改变应用、群、功能、资源策略、代码或环境时，先停止，再执行：

```sh
./start.sh setup
```

该命令展示当前待确认配置并更新内部摘要，只保存配置、不启动。确认后再 `./start.sh`。未改变范围和代码/环境的普通重启无需此步骤。密钥及持久配置文件按仅当前用户可读写保护。

## 受控验收模式

旧入口仍保留：

```sh
./start.sh daily 授权文件路径 授权摘要
./start.sh live 授权文件路径 授权摘要
```

它们继续使用限时、限预算和历史审计机制。只有需要受控真实测试时使用，不是默认日常入口。

离线演练仍可使用 `./start.sh offline`，它使用合成消息和独立离线数据库，不连接飞书。
