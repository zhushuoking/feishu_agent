## Mac启动和使用

在终端进入唯一项目目录：

```sh
cd <PROJECT_ROOT>
./status.sh
```

若已有Agent运行，不启动第二个消费者。完成新授权后，使用现有入口（将参数替换为该次实际签发值）：

```sh
./start.sh daily /实际路径/permit.json 实际SHA256
./status.sh
./logs.sh --follow
```

确认READY后，在授权群发送：

```text
@任务自动跟进Agent 会议 主题=项目复盘 时间=YYYY-MM-DD HH:mm 时长=60 参会人=@成员一,@成员二
```

机器人和每个成员均必须从飞书真正的@菜单选择，不能直接输入昵称冒充@。时间按北京时间且须在未来，时长1至1440分钟。参会人是消息实际mention对应的飞书用户；受邀、接受邀请和实际参会是不同状态。

停止仍使用原入口：

```sh
./stop.sh
./status.sh
```

## 结果如何判断

- “会议申请已提交”：表格写入已返回record_id，日程仍待自动化处理。
- “会议已创建（依据自动化回写）”：表格已进日历且两个ID非空，并取得有效视频地址。
- 日程成功但无视频地址：明确报告未取得有效视频会议链接，不虚构地址。
- 最多6次/10分钟回写查询后未完成：通知查表，不新增第二条记录。
- API超时或发送结果未知：停止自动重试，请对账，不重新发送同内容来强行恢复。不同消息ID会视为新申请，重复发消息仍可能创建另一场会议。

自动化没有开启前，新申请不会自动进日历。页面存在视频返回字段不能证明视频必定生成，仍需授权单样本闭环验证。
